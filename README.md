Unity开发的物理向派对游戏。
+ 项目内容：
  1.物理系统和角色控制：通过对角色身体各部分碰撞体和连接组件(Configurable Joint)的设置，实现了人物的主动布娃娃(Active Ragdoll)物理系统，同时在脚本中忽视可能相互影响的碰撞体间的碰撞；通过角色触地的主要连接部分控制角色整体的运动和转向，实现了独特的角色控制系统。
  2.网络通信：基于Photon Fusion 2构建实时多人联机框架，采用Host/Client模式结合状态同步机制，实现角色移动、物理交互与布娃娃系统的跨端一致性。利用Fusion的客户端预测+回滚机制保证输入响应与状态一致性。通过Networked状态变量与NetworkRigidbody3D实现关键状态同步。
  3.物理动画：对角色身体各部分单独控制动画同步，使得角色移动时身体的运动主要由物理系统控制，同时双脚由动画系统同步。
